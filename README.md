# Innovexsis Portfolio

The official portfolio website for Innovexsis — an ecosystem of AI-powered products spanning PropTech, GovTech, DevTools, AI companions, and automation infrastructure.

## Tech Stack

- **React 18** with TypeScript
- **Vite** for build tooling
- **Tailwind CSS** for styling
- **React Router** for navigation
- **Lucide React** for icons

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

This site is configured for Netlify deployment. The `netlify.toml` file handles build settings and SPA routing redirects.
